# AI Institution - Profile Based OS v2 (Final)

Architecture: Profile is MAIN, Kalolsavam is FEATURE inside profile.

Structure:
- Create Profile: Madrasa/School/College - each with different settings
- Inside Profile: Classes, Students (Chest No auto), Usthad, Attendance (Parent View), Hifz with Voice, Timetable, PDFs, Sadar Contact, Gallery
- Kalolsavam Feature: Event > Teams/Groups > Programs (Stage/Non-Stage) > Registration (10 programs per student) > Chest Search > Team View > ID Cards (print ready, photo base64 temp) > Stage Manager (Lot shuffle) > Judge Panel (marks) > Results

Languages: Malayalam, Arabic, English toggle

Firebase: ai-institution project - already connected. Just publish rules.

Deploy:
1. Upload to GitHub repo ai-institution
2. Settings > Pages > main/root > Save
3. Live in 2 mins
4. Or drop to pages.edgeone.ai

Firebase Rules: Copy from firestore.rules and Publish in Firestore > Rules

Free Tier: 1GB, 50K reads/day - enough for 1000+ students madrasa.
